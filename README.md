# Human vs AI Responses: A Statistical Comparison of Linguistic Characteristics

## About the Project

This project investigates whether there are measurable differences between human-written and AI-generated responses.

The project compares responses written by humans with responses generated by ChatGPT using the **Human–ChatGPT Comparison Corpus (HC3)** dataset.

The aim is not to build an AI detector or determine whether a particular response was written by a human or AI. Instead, the goal is to statistically compare some basic linguistic characteristics of the two types of responses.

## Research Question

> Are there measurable differences between human-written and AI-generated responses?

## Dataset

The dataset used in this project is the **Human–ChatGPT Comparison Corpus (HC3)** created by Hello-SimpleAI.

The original dataset contains **24,322 records**. Some records do not contain a ChatGPT response. After excluding records where either a human response or a ChatGPT response was unavailable, **23,867 paired records** were used for the analysis.

For each usable record, the first human response and the first ChatGPT response were selected for comparison.

### Dataset Source

- [HC3 Dataset on Hugging Face](https://huggingface.co/datasets/Hello-SimpleAI/HC3)
- [Hello-SimpleAI GitHub Repository](https://github.com/Hello-SimpleAI/chatgpt-comparison-detection)

## Features Analyzed

Five characteristics were selected for the comparison:

### 1. Response Length

The total number of words in each response.

### 2. Sentence Count

The estimated number of sentences, calculated by counting periods, exclamation marks, and question marks.

### 3. Average Sentence Length

The total number of words divided by the estimated number of sentences.

### 4. Vocabulary Diversity (TTR)

Type-Token Ratio (TTR) was used as a simple measure of vocabulary diversity.

$$
TTR = \frac{\text{Number of Unique Words}}{\text{Total Number of Words}}
$$

A higher TTR means that a larger proportion of the words are unique.

### 5. Punctuation per 100 Words

The number of selected punctuation marks (`.`, `!`, `?`, `,`, `;`, `:`) per 100 words.

This normalization was used because the two groups had different average response lengths.

## Statistical Analysis

The average value of each feature was calculated for human and ChatGPT responses.

Since each human response and ChatGPT response came from the same question, the differences between the paired responses were calculated.

A **one-sample t-test on the paired differences** was then used to determine whether the average difference was statistically different from zero.

## Results

| Feature | Human | ChatGPT | Difference (ChatGPT − Human) |
|---|---:|---:|---:|
| Response Length | 147.98 | 177.99 | +30.01 words |
| Sentence Count | 7.86 | 8.37 | +0.51 |
| Average Sentence Length | 19.89 | 21.99 | +2.09 words |
| Vocabulary Diversity (TTR) | 0.684 | 0.560 | −0.125 |
| Punctuation / 100 Words | 10.43 | 10.01 | −0.42 |

All five differences were statistically significant at **p < 0.001**.

However, statistical significance does not necessarily mean that a difference is practically large. For example, the difference in punctuation usage was relatively small.

## Key Findings

The analysis found that, in this dataset:

- ChatGPT responses were generally longer than human responses.
- ChatGPT responses contained slightly more sentences.
- ChatGPT sentences were longer on average.
- ChatGPT responses had lower average TTR.
- ChatGPT responses had slightly lower punctuation usage per 100 words.

These results indicate that human-written and ChatGPT-generated responses showed measurable differences in several basic writing characteristics.

However, these characteristics alone are **not sufficient to reliably determine whether an individual response was written by a human or generated by AI**.

## Limitations

This project has several limitations:

1. **Simple sentence counting**  
   Sentence counts were estimated using punctuation marks. This may incorrectly identify sentence boundaries in cases such as abbreviations or decimal numbers.

2. **TTR and response length**  
   TTR is affected by text length. Since ChatGPT responses were longer on average, response length may have influenced the TTR comparison.

3. **First response selection**  
   Some records contain multiple human and ChatGPT responses. Only the first available response from each category was used.

4. **Dataset-specific results**  
   The analysis was performed using the HC3 dataset. Therefore, the findings may not represent all human-written text or all AI-generated text from other AI systems and datasets.
